First completed run

From a Sample App Codespace

The prepared environment includes Rust, Cargo, and the current dw CLI.

  1. 1

    Configure one namespace

    Set the complete namespace runtime URL and separate client and worker credentials.

    DURABLE_WORKFLOW_RUNTIME_URL='https://cloud.example/api/runtime/v1/namespaces/<runtime-id>'
DURABLE_WORKFLOW_RUNTIME_NAMESPACE='orders'
DURABLE_WORKFLOW_CLIENT_TOKEN='dwr_client_...'
DURABLE_WORKFLOW_WORKER_TOKEN='dwr_worker_...'
  2. 2

    Run the workflow and activity

    The Sample App uses the pinned crate, one task queue, and a development build.

    scripts/rust-cloud.sh run
  3. 3

    Verify the completed result

    The command records SDK and CLI versions, shuts the worker down cleanly, and prints the Managed Waterline destination.

    "status_bucket": "completed"
"workflow_runtime": "rust"
"activity_runtime": "rust"
